# AI 提示詞紀錄 (Prompt History)

本文件記錄 Part A 階段使用 AI 生成「活動報名表單」前端程式碼所使用的 Prompt 與對話歷程。

### Prompt 1: 產生活動報名表單前端程式碼

**使用工具**：Gemini / ChatGPT / Claude  
**輸入提示詞 (Prompt)**：

> 請幫我生成一個單頁的「活動報名表單」前端（包含 HTML/CSS/JavaScript，請整合在單一 `index.html` 檔案中），並符合以下規格需求：
> 
> 1. **欄位需求**：
>    * 姓名（必填）
>    * Email（必填，需驗證格式）
>    * 票種（下拉選單：免費票 / 付費票）
>    * 報名人數（數字輸入框，1-10 人）
> 2. **金額邏輯**：
>    * 選擇「付費票」時，即時顯示總金額（單價 NT$500 × 人數）。
>    * 選擇「免費票」時，隱藏總金額顯示區塊。
> 3. **表單驗證與送出**：
>    * 點擊「送出報名」時，若欄位有誤，顯示對應錯誤訊息。
>    * 若驗證無誤，顯示「報名成功」。
> 
> 請提供具備簡潔現代感樣式（CSS）與完整互動邏輯（JS）的完整程式碼。
