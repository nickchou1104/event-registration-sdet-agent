### 當時工程師輸入的具體原始提示詞 (Prompt) 內容

```
請作為一位資深前端工程師，為我生成一個單頁的活動報名表單前端程式碼。
要求使用 HTML、CSS (嵌入 `<style>` 標籤) 和 Vanilla JavaScript。

**表單功能需求：**
1.  **基本結構**：
    *   頁面標題為「活動報名表單」。
    *   表單應置中顯示，最大寬度約 400px，並具備陰影和圓角。
    *   頁面語言設定為繁體中文 `zh-TW`。
2.  **表單欄位**：
    *   **姓名**：文字輸入框，必填，有紅色星號標示，placeholder 為「請輸入真實姓名」。
    *   **Email**：Email 輸入框，必填，有紅色星號標示，placeholder 為「example@domain.com」。
    *   **票種**：下拉選單，包含「免費票」和「付費票 (NT$500)」兩個選項，預設為「免費票」。
    *   **報名人數**：數字輸入框，預設值為 1，限制人數範圍為 1 到 10。
3.  **動態金額計算**：
    *   當「票種」選為「付費票」時，下方需顯示「總金額: NT$ [計算結果]」。
    *   金額計算方式為「報名人數 * 500」。
    *   當「票種」選為「免費票」時，金額顯示區域需隱藏。
    *   「報名人數」或「票種」改變時，應即時更新總金額。
4.  **表單驗證 (JavaScript)**：
    *   送出表單時，需阻止頁面預設重新整理行為。
    *   **姓名**：必填，若為空則在表單下方顯示錯誤訊息。
    *   **Email**：必填，且需進行基礎 Email 格式驗證 (例如：包含 `@` 和 `.` )。若不符合則在表單下方顯示錯誤訊息。
    *   **報名人數**：需在 1 到 10 之間，若超出範圍則在表單下方顯示錯誤訊息。
    *   所有驗證錯誤都應以紅色背景和文字顯示在表單下方。
    *   每次提交前，需清除之前的訊息。
5.  **提交結果訊息**：
    *   若所有驗證通過，則在表單下方顯示「報名成功」的訊息，此訊息應為綠色背景和文字。
6.  **樣式設計 (CSS)**：
    *   整體採用簡潔、現代的設計風格，類似 Tailwind CSS 的基本元素設計（例如：輸入框、按鈕的圓角、陰影、藍色按鈕）。
    *   錯誤和成功訊息的樣式需清晰區分。
    *   確保基本的響應式佈局，並在手機等小螢幕上保持可用性。

請直接提供完整的 HTML 文件代碼，包含所有 CSS 和 JavaScript。
```
