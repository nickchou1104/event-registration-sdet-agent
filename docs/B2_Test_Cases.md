# 測試案例設計 (Test Cases)

### [TC-001] 正向報名 - 免費票
*   **測試情境分類**：正向 (Happy Path)
*   **優先級 (Priority)**：High
*   **前置條件**：進入表單首頁
*   **測試步驟**：
    1. 姓名欄位輸入「張三」。
    2. Email 欄位輸入「test@example.com」。
    3. 票種下拉選單選擇「免費票」。
    4. 報名人數維持預設值「1」。
    5. 點擊「送出報名」按鈕。
*   **預期結果**：畫面隱藏總金額區塊，點擊送出後成功顯示「報名成功」。

### [TC-009] 跨欄位連動 - 切換票種之金額顯示狀態
*   **測試情境分類**：跨欄位連動 (Cross-field)
*   **優先級 (Priority)**：High
*   **前置條件**：進入表單首頁
*   **測試步驟**：
    1. 票種選擇「付費票」，人數輸入「3」（確認畫面顯示總金額 1500）。
    2. 將票種下拉選單切換回「免費票」。
*   **預期結果**：總金額顯示區塊必須立即隱藏，且切回付費票時需重新計算正確金額。

### [TC-010] 安全性測試 - 姓名欄位 XSS 防禦
*   **測試情境分類**：安全性 (Security)
*   **優先級 (Priority)**：Low
*   **前置條件**：進入表單首頁
*   **測試步驟**：
    1. 在姓名欄位填寫 `<script>alert('XSS')</script>`。
    2. 填寫正確 Email 並點擊「送出報名」。
*   **預期結果**：系統應將輸入字串進行轉義（Escape）處理，不跳出 Alert 警示視窗，防止腳本執行。
